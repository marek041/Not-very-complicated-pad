# Not-very-complicated-pad
simple macro pad. 6 keys with oled display and Xiao RP2040. Macro pad for simple tasks like ctrl+c, ctrl+v, etc.

## Features: 
* 6 keys
* 128x32 oled display
* 3 leds
* cool case (:

  ## Cad design
  This includes 3d printed case of 3 parts, everything is connected with M3 bolts screwed in plastic.
  It was made in Fusion360 and components imported from KiCad (i added step files so it could generate full PCB with components )
  it is all in cad folder
